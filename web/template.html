RxReadable

Read a handwritten prescription → structured medicines → plain-English explanation

Academic demo with fictional data. Readings can be wrong and are not medical advice. Always confirm with the doctor or a pharmacist.

Runs entirely in your browser: JavaScript port of the RxReadable parser (fuzzy drug matching, dose/frequency/duration extraction) and a character n-gram TF-IDF retriever over a 33-drug, 43-abbreviation knowledge base. Samples show real Tesseract output from the Python pipeline. Live OCR and Gemini explanations need the Python app (streamlit run app.py).
